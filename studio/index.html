검토흰토 STUDIO예시 화면

프로젝트

  • 협동 게임 (예시)
  • 프로토타입 (예시)

대화

      문서, 이미지, 코드, Unity 사이를 오가며 프로젝트를 다시 설명하는 일을 줄입니다.

      자료를 첨부하고 스킬을 고르면 실제 작업에 필요한 도구를 함께 씁니다. 작업이 끝나면 답변과 변경한 파일, 실행 결과를 보고 다음에 무엇을 할지 결정합니다.

      How It Runs

      1. 프로젝트 선택

        팀에서 부여한 계정으로 로그인하면 사용할 수 있는 Claude 또는 Codex 모델과 생각 깊이 설정이 표시됩니다.

      2. 폴더 연결

        내 PC의 프로젝트 폴더를 고릅니다. Unity 프로젝트라면 준비 상태를 확인하고 작업을 허용할 수 있습니다.

      3. 대화로 요청

        기획서, 스크린샷, 코드, 표 자료를 붙이고 작업에 맞는 스킬을 고릅니다.

      4. 과정과 결과 확인

        분석 내용, 변경한 파일 경로, 실행한 명령과 결과를 봅니다. 다음 메시지를 대기시킬 수도 있습니다.

      5. 이어서 작업

        대화 제목을 바꾸고 답변을 복사하며, 프로젝트별로 이전 작업을 찾아 이어갑니다.

      Features

      게임 제작 스킬

      분야를 열고 검색과 엔진 필터로 찾습니다. 작업 기록에서 내가 고른 스킬과 AI가 실제로 읽은 스킬을 확인할 수 있습니다.

      • 기획
      • 디자인
      • 개발
      • 사운드
      • 테스트
      • 출시

      팀 배정과 사용 기록

      관리자가 프로젝트와 참가자별로 AI 계정을 배정하고, 팀·프로젝트, 개인, 담당 업무, AI 계정 기준으로 기록을 조회해 CSV로 내보냅니다.

      그래프는 예시입니다.

      이미지와 문서 첨부

      PDF는 본문과 페이지 화면을 함께 검토하고, Excel은 시트와 셀, 수식을 살펴봅니다.

      • 이미지
      • PDF
      • Word
      • PowerPoint
      • Excel
      • 코드

      작업 폴더와 Unity 연결

      지정한 폴더를 기준으로 요청과 권한에 따라 파일을 읽거나 수정합니다. 환경이 갖춰져 있으면 로그 확인, 테스트, 빌드를 요청합니다.

      브라우저 작업

      Studio 전용 Chrome으로 자료를 찾고, 사용자의 승인을 받아 내 Chrome의 탭을 여러 개 지정해 넘길 수 있습니다.

      macOSStudio Mac Preview로 제공합니다.

      개발 중인 기능개인 체크리스트와 개별 할 일 첨부, 개인·프로젝트 메모리, 대화 간 작업 요청, 관리자용 AI 계정 잔여 한도 화면.
